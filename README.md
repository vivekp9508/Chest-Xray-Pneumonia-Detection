# Chest X-Ray Pneumonia Detection using Deep Learning

This project is a deep learning-powered medical image classification web application that detects Pneumonia from Chest X-Ray scans using a fine-tuned ResNet50 model.

## Features
- Upload Chest X-Ray image
- Predict Normal or Pneumonia
- Confidence Score
- Grad-CAM Explainability Heatmap

## Tech Stack
- Python
- TensorFlow / Keras
- ResNet50
- Gradio
- OpenCV
